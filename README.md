# Hazri app downloads

This repository only holds the Android APK files for the Hazri attendance app. It contains no source code.

**Download the latest version:** https://github.com/madanmohanmajumdar3291-bot/-hazri-releases/releases/latest/download/hazri.apk

All versions are on the [Releases](../../releases) page. The `parts/` folder holds the APKs split into pieces, and a workflow reassembles them, checks their SHA-256, and publishes each version as a release.
